# Frontend Design Skill — CalculaFiscal Edition

Follow the global `frontend-design` guidelines with specialized focus on **Swiss Financial Precision & High-Conversion Utility**:
1. **Typography**: Use `Plus Jakarta Sans` for headings/UI and `JetBrains Mono` (`font-mono tabular-nums`) for all monetary values (`R$`), tax rates (`%`), and CNAE codes (`6201-5/01`).
2. **Visual Data Bars**: Accompany numerical comparisons (CLT vs PJ, Simples Nacional Anexo III vs V) with visual stacked proportion bars so users immediately see how much goes to taxes vs. net pocket income.
3. **Interactive Ergonomics**: Provide 1-tap preset pills for common salaries/revenues, smooth range sliders, and 1-click "Copiar Resumo / WhatsApp" sharing to maximize dwell time and organic virality.
4. **Core Web Vitals Discipline**: Load fonts via `next/font/google` (`display: swap`) and maintain strict `min-h` reservations on `AdSlot` components for Zero CLS.
